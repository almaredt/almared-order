# ALMARED Order — اپ اندروید ساخت اوردر لیست

اپ اندروید برای ساخت سریع اوردر لیست با عکس، روی گوشی. کاملاً آفلاین کار می‌کند و به اینترنت یا API نیازی ندارد.

## امکانات
- **عکاسی سریع:** دوربین زنده باز می‌شود و هر عکس یک ردیف جدید می‌سازد. بعد از هر عکس پنل کوچکی برای Code / Unit / Ctn / Price باز می‌شود (اختیاری است). کد بعدی خودکار پیشنهاد می‌شود، مثلاً بعد از TZR A1، کد TZR A2.
- افزودن چند عکس با هم از گالری، و افزودن ردیف بدون عکس.
- محاسبهٔ خودکار: QTY = Unit × Ctn و Total = QTY × Price. جمع کل، Tranzit، کمیسیون درصدی و TOTAL نهایی.
- چند سفارش جداگانه، با جستجو، کپی سفارش و حذف.
- **خروجی‌ها:** PDF با طرح فاکتور (چند صفحه‌ای و با عکس)، Excel با عکس داخل سلول و فرمول، چاپ مستقیم از اندروید، ارسال به واتساپ و برنامه‌های دیگر، و فایل پشتیبان JSON.
- فایل‌ها در پوشهٔ `Downloads/ALMARED Order` ذخیره می‌شوند.

## ساخت APK — روش ۱: GitHub (بدون نصب هیچ برنامه‌ای)
1. در github.com یک Repository جدید بسازید (Private هم مشکلی ندارد).
2. محتوای این پوشه را آپلود کنید: **Add file → Upload files**. پوشهٔ `.github` هم حتماً باید آپلود شود.
3. به تب **Actions** بروید. کار «Build APK» خودکار شروع می‌شود و حدود ۴ دقیقه طول می‌کشد.
4. وقتی کار سبز شد، روی آن کلیک کنید و از بخش **Artifacts** فایل `ALMARED-Order-APK` را دانلود کنید.
5. فایل zip را باز کنید و `ALMARED-Order.apk` را روی گوشی نصب کنید. اگر گوشی پرسید، گزینهٔ نصب از منابع ناشناس را تأیید کنید.

## ساخت APK — روش ۲: Android Studio
پوشه را با **File → Open** باز کنید، صبر کنید Gradle Sync تمام شود، و بعد **Build → Build App Bundle(s)/APK(s) → Build APK(s)** را بزنید.

## امضای اختصاصی (برای Google Play)
این ۴ Secret را در GitHub (Settings → Secrets → Actions) اضافه کنید:
`KEYSTORE_BASE64` (فایل keystore به base64)، `KEYSTORE_PASSWORD`، `KEY_ALIAS`، `KEY_PASSWORD`.
اگر این‌ها را نگذارید، APK با کلید debug امضا می‌شود. این برای نصب روی گوشی‌های خودتان کافی است.

## ساختار
- `app/src/main/assets/www/` — خود اپ (HTML/CSS/JS). همین پوشه در مرورگر کامپیوتر هم اجرا می‌شود.
- `app/src/main/java/.../MainActivity.java` — پوستهٔ اندروید شامل WebView، دوربین، ذخیره، اشتراک‌گذاری و چاپ.
- Package name: `com.almared.orderlist`
